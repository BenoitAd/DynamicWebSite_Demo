# Dynamic E-commerce Website

A simple yet dynamic e-commerce website built with PHP and MySQL. This project demonstrates the ability to create an interactive web application where users can browse products, view product details, and manage a shopping cart.

## 🚀 Features
- 🏠 **Home Page**: Displays a list of products.
- 🛒 **Product Page**: View product details and add items to the cart.
- 📦 **Shopping Cart**: Manage selected items.
- 💾 **Database**: MySQL database initialized at application startup.
- 🔄 **Dynamic Rendering**: Products and cart updates without page reloads.

## 🛠️ Technologies Used
- **PHP**: Server-side scripting.
- **MySQL**: Database management.
- **Docker**: Containerization for easy deployment.
- **HTML, CSS, JavaScript**: Frontend development.

## 🏗️ Setup & Installation

### Prerequisites
- Docker & Docker Compose installed on your system.

### Run Locally with Docker
```sh
# Clone the repository
git clone https://github.com/yourusername/dynamic-ecommerce.git
cd DynamicWebSite_Demo

# Build and start the container
docker-compose up --build

# Access the application in your browser
http://localhost:8080
```
